# 新模式与本地保存验证

验证日期：2026-09-17。环境：Windows、Playwright Chromium headless、开发服务器 `http://127.0.0.1:5173`，单个 worker，1440 × 1000。

执行：

```powershell
npx tsc --noEmit
npx playwright test tests/e2e/modes.spec.ts --reporter=line --output=artifacts/modes-e2e-final
```

结果：类型检查通过；浏览器测试 **6 / 6 通过，30.7 秒**。

三项每日任务还分别验证：普通生涯胜场、比赛数和累计分数保持为零；历史仅新增挑战记录；每日独立存档仅出现所完成的任务，其它两项无最佳成绩。阵容、每日及淘汰流程均监听浏览器未处理异常并确认没有错误。

## 加速与测试边界

开赛、选择球员、模式切换、查看赛程、下一轮和继续比赛均通过 UI 完成。比赛时间使用开发环境的 `__NBA.step` 加速；胜利策略只读取快照并发送普通 `InputFrame`，不修改模拟器隐藏状态、不直接写比分或结算状态。杯赛胜利测试只固定用于生成种子的外部时钟，使对阵与随机序列可重复；60 Hz 输入期间不插入空键盘 RAF 帧，避免提前松开正在蓄力的投篮。

测试覆盖首轮胜利晋级、第二轮恢复，以及首轮失败后的完整淘汰结果。它不宣称通过浏览器连续赢完四轮；四轮夺冠与各 bracket 位置的分数方向另由 `tests/tournament.test.ts` 验证。

测试执行时应暂停会引发 Vite 整页刷新的源码编辑。已结束的杯赛赛程入口位于冠军赛模式页；进行中的杯赛可从主页直接继续。
